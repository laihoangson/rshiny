
# quarantine

This R package provides data and an interactive Shiny application to
explore COVID-19 quarantine breach data in Australia for **ETC5523
Assignment 4**.

## Installation

You can install the development version of this package from GitHub
with:

``` r
# install.packages("remotes")
remotes::install_github("YOUR-GITHUB-USERNAME/YOUR-REPO-NAME")
```

## Example Usage

Once installed, you can load the package and launch the interactive
Shiny app.

``` r
library(quarantine)  

# Launch the interactive application
launch_app()

# You can also directly access the data
head(breaches_data)
```
